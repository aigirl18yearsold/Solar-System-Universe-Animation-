Solar System Universe Animation ☀️🌍✨
A cinematic animated Solar System in the Universe built using pure HTML5 Canvas + JavaScript.
Planets revolve around the glowing Sun while stars and galaxy particles move through deep space to create a beautiful universe effect.
🚀 Features
☀️ Glowing animated Sun
🪐 Revolving planets
🌌 Deep space background
✨ Twinkling stars
🌠 Moving galaxy particles
📱 Fullscreen responsive design
⚡ Lightweight and fast
🎨 Pure HTML, CSS, and JavaScript
🛠 Technologies Used
HTML5
CSS3
JavaScript
HTML Canvas API
